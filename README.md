# blog-sitesi-tasarlama
blog sitesi tasarlama html+css
🖥️ Özellikler

Basit ve modern HTML yapısı

Üst kısımda başlık ve navigasyon menüsü

Kart tasarımı ile gönderi özetleri

Her gönderi için başlığa tıklayarak detay sayfasına geçiş

Telif hakkı bilgisi içeren footer bölümü

🔧 Kullanılan Teknolojiler

HTML5

CSS3

(İsteğe bağlı) Görseller için img klasörü

📜 Sayfa Açıklamaları
index.html

Blog sitesinin ana sayfasıdır.
İçerisinde:

Üst menü (Ana Sayfa – Blog Gönderisi)

Son gönderilerin kart yapısı içinde listelenmesi

Footer alanı

bulunur.

post.html

Her blog gönderisi için tekil içerik sayfası olarak kullanılabilir.
(Not: Projenin örnek yapısında sadece link verilmiştir.)

🖼️ Görseller

Projede kullanılan görseller:

cat.jpg → Blog yazısı 1 için

Türk-Dizileri.png → Blog yazısı 2 için

Bu dosyaların img klasöründe bulunması gerekmektedir.

▶️ Kullanım

Dosyaları bir proje klasörüne yerleştirin.

Tarayıcıdan index.html dosyasını açın.

Blog gönderisi başlıklarına tıklayarak detay sayfasına geçin.
